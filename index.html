Engineering Notes
Problem

Small shops need a steady stream of promotional content but rarely have the time to produce it. Long documents hide the one answer someone actually needs. Both projects start from that friction.

Architecture

Brief AI chains product parsing, caption generation and image generation as a multi-step LangGraph workflow. Decoda runs an ingestion, chunking, embedding, retrieval and response pipeline.

Implementation

Workflows were defined first, then models and APIs were integrated stage by stage — each step tested on its own before the next component was connected.

What I Learned

Clear boundaries between workflow stages matter more than the model choice, retrieval quality decides answer quality, and reviewing AI-generated code is a skill in itself.

My Role

My involvement covers product and engineering decisions across the build — the code was developed with AI assistance and reviewed, not written entirely by hand.

  • Understanding requirements
  • Defining workflows
  • Planning architecture
  • Integrating AI models & APIs
  • Reviewing AI-generated code
  • Testing & debugging
  • Connecting components
  • Improving workflows
